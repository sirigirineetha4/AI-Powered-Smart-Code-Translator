# 🤖 AI-Powered Smart Code Translator

An AI-powered full-stack web application that helps developers translate, understand, analyze, and optimize source code using Google's Gemini API.

## ✨ Features

- 🔄 Translate code between C, C++, C#, Java, and Python
- 📊 Analyze time and space complexity
- ⚡ Optimize code with AI-powered suggestions
- 📖 Get clear explanations of source code
- 🔐 Email/password and Google OAuth authentication
- 🔑 JWT-based authorization
- 📝 Store and manage code operation history
- 💻 Interactive code editor using Monaco Editor

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, React Router, Axios, Monaco Editor, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, Google OAuth, bcryptjs
- **AI:** Google Gemini API

## 🌐 Supported Languages

- C
- C++
- C#
- Java
- Python
